## Title
LinkGuard: വ്യാജലിങ്ക് പരിശോധന

## Short description
WhatsApp, SMS ലിങ്ക് തുറക്കും മുമ്പ് തട്ടിപ്പ് നോക്കും. ഒരിക്കലും തടയില്ല.

## Full description
WhatsApp, Telegram അല്ലെങ്കിൽ SMS-ൽ ഒരു ലിങ്ക് വന്നു, അത് സുരക്ഷിതമാണോ എന്ന് ഉറപ്പില്ലേ? നിങ്ങൾ ടാപ്പ് ചെയ്യുന്ന ഓരോ ലിങ്കും, തുറക്കുന്നതിന് മുമ്പ്, LinkGuard ഒരു നിമിഷത്തിനുള്ളിൽ പരിശോധിക്കുന്നു.

സുരക്ഷിതമായ ലിങ്കുകൾ നിങ്ങളുടെ പതിവ് ബ്രൗസറിൽ ഉടൻ തുറക്കും, നിങ്ങൾ ഒന്നും കാണില്ല. ഒരു ലിങ്ക് തട്ടിപ്പാണെന്ന് തോന്നിയാൽ, കാരണം വിശദീകരിക്കുന്ന ഒരു വ്യക്തമായ മുന്നറിയിപ്പ് ഇംഗ്ലീഷിലോ ഇന്ത്യയുടെ 22 ഔദ്യോഗിക ഭാഷകളിൽ ഏതിലെങ്കിലുമോ നിങ്ങൾക്ക് കാണാം. LinkGuard ഒരിക്കലും തടയില്ല: നിങ്ങൾക്ക് എപ്പോഴും "എന്നാലും തുറക്കുക" തിരഞ്ഞെടുക്കാം.

LinkGuard എന്തെല്ലാം കണ്ടെത്തുന്നു
• അറിയപ്പെടുന്ന പേരുകൾ അനുകരിക്കുന്ന വ്യാജ ബാങ്ക്, വാലറ്റ്, ഡെലിവറി വെബ്സൈറ്റുകൾ, ഒരുപോലെ തോന്നുന്ന അക്ഷരങ്ങൾ, മാറ്റിയ അക്കങ്ങൾ, ചെറിയ അക്ഷരമാറ്റങ്ങൾ എന്നിവ ഉൾപ്പെടെ
• Play Store-ന് പുറത്തുനിന്നുള്ള ആപ്പ് ഡൗൺലോഡുകൾ (APK ഫയലുകൾ), "നിങ്ങളുടെ KYC അപ്ഡേറ്റ് ചെയ്യുക" സന്ദേശങ്ങളിലെ സാധാരണ തന്ത്രം
• ലിങ്കുകൾക്ക് പിന്നിൽ ഒളിപ്പിച്ച UPI പേയ്മെന്റ് അഭ്യർത്ഥനകൾ, എന്തെങ്കിലും അംഗീകരിക്കും മുമ്പ് ആർക്ക് എത്ര പണം നൽകും എന്ന് കാണിക്കുന്നു
• അറിയപ്പെടുന്ന തട്ടിപ്പ്, അപകടകരമായ വെബ്സൈറ്റുകൾ, പ്രമുഖ അന്താരാഷ്ട്ര സുരക്ഷാ ഡാറ്റാബേസുകളിൽ നിന്ന് ശേഖരിച്ച് ദിവസവും പുതുക്കുന്ന പതിനായിരക്കണക്കിന് സൈറ്റുകളുടെ പട്ടികയിൽ നിന്ന്
• അസാധാരണമായ വെബ് വിലാസങ്ങൾ, അക്കങ്ങൾ മാത്രമുള്ള വിലാസങ്ങളും കുറച്ച് ദിവസത്തേക്ക് ഉണ്ടാക്കിയ ഡൊമെയ്നുകളും പോലെ
• തീരെ പുതിയ വെബ്സൈറ്റുകൾ, തട്ടിപ്പുകാർ കുറച്ച് ദിവസം ഉപയോഗിച്ച് ഉപേക്ഷിക്കുന്നവ
• ഒരേ ആഴ്ചയിൽ നിരവധി LinkGuard ഉപയോക്താക്കൾ തട്ടിപ്പാണെന്ന് റിപ്പോർട്ട് ചെയ്ത ലിങ്കുകൾ
• ചെറിയ ലിങ്കുകൾ (bit.ly പോലുള്ളവ) ആദ്യം തുറന്നുനോക്കുന്നു, അതിനാൽ യഥാർത്ഥ ലക്ഷ്യസ്ഥാനം പരിശോധിക്കപ്പെടുന്നു

LinkGuard ഒരു ബ്രൗസർ അല്ല
ലിങ്കുകൾ ആദ്യം കാണാൻ വേണ്ടി മാത്രമാണ് Android, LinkGuard-നെ നിങ്ങളുടെ "ബ്രൗസർ ആപ്പ്" ആയി കാണിക്കുന്നത്. ഇത് ഒരിക്കലും വെബ് പേജുകൾ കാണിക്കില്ല. ഓരോ ലിങ്കും നിങ്ങൾ ഇപ്പോൾ ഉപയോഗിക്കുന്ന Chrome പോലുള്ള ബ്രൗസറിൽ തന്നെ തുറക്കും, നിങ്ങളുടെ ബുക്ക്മാർക്കുകൾ, ഹിസ്റ്ററി, സേവ് ചെയ്ത പാസ്‌വേഡുകൾ, ടാബുകൾ എല്ലാം അതുപോലെ തന്നെ ഉണ്ടാകും.

സ്വകാര്യത ആദ്യം
• നിങ്ങൾ തുറക്കുന്ന ലിങ്കുകളുടെ ഹിസ്റ്ററി LinkGuard സൂക്ഷിക്കുന്നില്ല, അവ ഒരിക്കലും ഞങ്ങൾക്ക് അയയ്ക്കുന്നുമില്ല.
• അക്കൗണ്ട് ഇല്ല, പരസ്യങ്ങൾ ഇല്ല, അനലിറ്റിക്സ് ഇല്ല, ട്രാക്കറുകൾ ഇല്ല.
• മിക്ക പരിശോധനകളും നിങ്ങളുടെ ഫോണിൽ തന്നെ നടക്കുന്നു. പരിചയമില്ലാത്ത വെബ്സൈറ്റുകൾക്ക്, വെബ്സൈറ്റിന്റെ പേരിന്റെ ഒരു ചെറിയ, മാറ്റിമറിച്ച അടയാളം മാത്രമേ LinkGuard അയയ്ക്കൂ, അതിനാൽ നിങ്ങൾ ഏത് സൈറ്റ് തുറന്നു എന്ന് ഞങ്ങൾക്ക് അറിയാൻ കഴിയില്ല.
• റിപ്പോർട്ടുകൾ അജ്ഞാതമാണ്: നിങ്ങളുടെ റിപ്പോർട്ടുകൾ തമ്മിൽ ബന്ധിപ്പിക്കാനോ നിങ്ങളെ കണ്ടെത്താനോ കഴിയില്ല.

എങ്ങനെ തുടങ്ങാം
1. LinkGuard തുറന്ന് "ഡിഫോൾട്ട് ബ്രൗസർ ആക്കുക" ടാപ്പ് ചെയ്യുക.
2. നിങ്ങളുടെ ലിങ്കുകൾ തുറക്കേണ്ട ബ്രൗസർ തിരഞ്ഞെടുക്കുക.
3. Telegram, Instagram, Facebook, LinkedIn പോലുള്ള ആപ്പുകൾ പലപ്പോഴും ലിങ്കുകൾ ആപ്പിനുള്ളിൽ തന്നെ തുറക്കും, അവിടെ LinkGuard-ന് അവ പരിശോധിക്കാൻ കഴിയില്ല. ആ ആപ്പിന്റെ സെറ്റിംഗ്സിൽ അതിന്റെ ഇൻ-ആപ്പ് ബ്രൗസർ ഓഫ് ചെയ്യുക, അല്ലെങ്കിൽ "ബ്രൗസറിൽ തുറക്കുക" തിരഞ്ഞെടുക്കുക.

Android 8-ലും പുതിയ പതിപ്പുകളിലും, 2 GB മെമ്മറിയുള്ള ഫോണുകളിലും പ്രവർത്തിക്കും.
